# The Book of Mormon Revamped
*Creative Discipleship Project: Everett Taylor*

## Folders

- `/code`: Contains the Python scripts I used to process the HTML file of the Book of Mormon text.
- `/bom_text`: Contains the original Project Gutenberg HTML Book of Mormon text (called `bom_full_text.html`), as well as a midway-processed version (called `bom_content.html`).
    - `/the_bom`: Contains the folders and text files extracted from the HTML file: one folder for each book of the Book of Mormon, and one .txt file for each chapter.

## Summary

I wanted to turn the Book of Mormon into a novel. I didn’t want to change the words themselves: I wanted to present the words of the Book in flowing, logical paragraphs instead of stilted verses. This idea was inspired by an original 1830 copy of the Book of Mormon I saw on a field trip to the HBLL Special Collections. It was printed without verses or double columns, ready to be read, pored over, and devoured. I wanted the same experience for myself, so I set out to create a digital version of the Book of Mormon that mimicked the original.

My project is still undone. Translating, type-setting, and publishing the Book of Mormon for the first time took months of effort, and I only had a few weeks. (I had so little time because I switched to this project when I lost interest in my original one.) Fortunately, instead of working with paper, ink, and a printing press, I was working with modern computing power. I downloaded a public domain copy of the Book of Mormon from Project Gutenberg, formatted in HTML. I wrote a Python program that extracted the text of each book and chapter, stripped the versification and paragraphing, and organized it as plain text files in a folder tree: one file for each chapter and one folder for each book.

The next step I planned to take was to write another Python program to use a cloud-based AI model to break each chapter into logical, flowing paragraphs. This was something I had never done before, so developing a working framework took time. When the deadline came, I had made significant progress, but a few critical, unresolved issues kept me from completing this step. My program could only handle about half of a chapter at a time, and I have not yet found a solution.

Despite it being unfinished, I gained much from this project. It was unique because it lay at the intersection of my faith and my talents. I love programming, and I love the Book of Mormon, and this project enabled me to connect the two. While working on it, my appreciation for the coming forth of the Book of Mormon was also increased. I realized how difficult it must have been to translate and print the book without the help of a computer. Gaining this appreciation strengthened my spiritual connection to the Book of Mormon and the witness of Jesus Christ it bears.

Thanks for reading, and enjoy!
